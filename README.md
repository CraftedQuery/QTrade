# AI Trading Lab — agent pack

Use this folder as the root instructions for **Grok Build** or **Claude Code**.
It is a constraint layer on top of the v1.3 external-review package, not a replacement for the research philosophy in that package.

## Files

| File | Purpose |
|---|---|
| `AGENTS.md` | Binding rules for Grok Build and any agent |
| `CLAUDE.md` | Extra pointer for Claude Code |
| `docs/00_owner_mandate.md` | Fill in hours, budget, capital, drawdown |
| `docs/01_solo_agent_build.md` | 8–12 week slice an agent is allowed to build |
| `docs/02_coding_agent_choice.md` | Grok Bot vs Grok Build vs Claude Code |

## Start

1. Fill `docs/00_owner_mandate.md`.
2. Put these files at the root of a new git repo.
3. Run Grok Build or Claude Code in **plan mode**.
4. Approve only week 1–2 from `docs/01_solo_agent_build.md`.

Do not start from “build the full AI trading lab.”
